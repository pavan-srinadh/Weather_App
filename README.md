# Weather_App

# 🌦️ Advanced Animated Weather App

An interactive and visually rich **Weather Application** built using **HTML, CSS, and JavaScript**. This app fetches real-time weather data and dynamically updates the UI with beautiful animations based on current weather conditions.

Link🔗 https://pavan-weather1.netlify.app/

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display (°C)
* 💧 Humidity and 🌬 wind speed details
* ⚠️ Error handling for invalid city input
* 🎨 Dynamic UI with **glassmorphism design**
* 🌤️ Weather-based animations:

  * ☀️ Clear → Sun animation
  * ☁️ Clouds → Moving clouds
  * 🌧 Rain → Animated rainfall
  * ⚡ Thunderstorm → Lightning effect
* 🎯 Responsive and clean layout

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling, animations, gradients
* **JavaScript (Vanilla)** – Logic and API handling
* **OpenWeatherMap API** – Weather data

## ⚙️ How It Works

1. User enters a city name
2. App sends a request to **OpenWeatherMap API**
3. Weather data is fetched and parsed
4. UI updates dynamically:

   * Weather details displayed
   * Background and animations change based on condition

---

## 🔑 API Setup

This app uses the **OpenWeatherMap API**.

1. Get your API key from: https://openweathermap.org/api
2. Replace the API key in the code:

```javascript
const apiKey = "YOUR_API_KEY";
```
